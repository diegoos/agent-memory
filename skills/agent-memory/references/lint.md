# `/agent-memory lint`

Six-pass health check of `.agents/memory/`, the installed method, and hook wiring. Report findings. Fix only what Boundary allows. Promotion and pruning belong to `/agent-memory consolidate` — not `lint --fix`.

**Severity (report only what needs action):**

| Band         | Meaning                                                                                                                                                      | Fix offer?                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| **errors**   | Broken structure (links, required headings, orphans, stale or closed-placeholder `active-work` files)                                                                              | Yes — safe / `--fix` as below                     |
| **warnings** | Actionable drift (stale Checkpoint, uncovered hook evidence, `pending-doc-met`, wiring, budgets, semantic defects, typos, contradictions, cold-session gaps) | Yes — sync / consume / consolidate / confirm edit |
| **info**     | Expected or ephemeral noise (missing hook state file, dirty-tree evidence re-queue when meaning already covers, open valid `pending-doc` backlog)            | **No** — do not list under Fix offer              |

Do not invent warnings for healthy bootstrap output (open `pending-doc` whose `Invalidate when` is still false) or for hook path lists that merely mirror an already-documented dirty tree.

## Boundary

- **May edit** (confirm): paths in `SKILL.md` `allowed-tools`, plus `.agents/memory/.gitignore` when copying vendor ignore rules. `decisions.md` / `learnings.md` / `learnings-*.md` need a host prompt. **Not** `instructions.md` (that is `/agent-memory update`).
- **`--fix` may delete only:** stale per-branch `active-work/<branch>.md` (branch gone), `closed-placeholder-resume:` files whose basename is **not** the current git branch, leftover `active-work/TEMPLATE.md` (`template-in-memory`; scaffold SoT is this skill's `references/active-work-template.md`), and confirmed **delegation-canary** blocks in `CLAUDE.md` / `GEMINI.md` that `@AGENTS.md`. `TEMPLATE.md` deletion is safe. `--fix` **never deletes** anything else. Delegation removal edits only the agent-memory delimiters (show diff, confirm). `--fix` never removes blocks from `AGENTS.md` when it is a shared carrier for codex/opencode/delegation.
- Semantic promotion/pruning, Relates rewrite, learnings split-merge, rolling closed log: consolidate or confirm edit — not silent `--fix`.
- No `markdownlint` here — Markdown style is the source repo's concern, not installed memory.

## Steps

1. **Guard.** If `.agents/memory/` does not exist, suggest `/agent-memory init` and stop.
   **Done when:** memory exists, or init is the only output.

2. **Structural.** Read `references/lint-structural.md` and run the two scripts it names (cwd on each). Collect finding IDs. `wrong-cwd:` means the script cwd was wrong — re-run from the cwd named in `references/lint-structural.md` (memory emitter: `.agents/memory/`; root emitter: project root); no content fix. Also report: missing `.agents/memory/.version` (manual install; `update` cannot track); missing `.agents/memory/.gitignore` or one that does not list **all** of `.hook-sync-state`, `.hook-sync-state.lock`, and `.hook-sync-state.*` — copy from this skill's `vendor/memory/gitignore` (pack-safe name; Write destination as `.agents/memory/.gitignore`).
   **Done when:** both structural scripts ran; stdout is the finding list.

3. **Consistency.** Memory files name the same live work.
   - Required headings for resume (agent-owned) — core only: `current.md` `## In progress`; each `active-work/*.md` (except `TEMPLATE.md`) `## Task`, `## Next step`, `## Validation`, plus a `Checkpoint:` line. Optional sections (`## Progress`, `## Hold`, `## Blockers`, …) exist only with content (`empty-optional-section:`).
   - `current.md` _In progress_ that names `active-work/FOO` while that file is missing is `current-stale-branch:` — do not warn merely because a local active-work file is unlisted.
   - Index lists every recall file that exists (`orphan:`). No graph-tree folders (`graph-tree:`). No leftover `TEMPLATE.md` (`template-in-memory:`). Two `Status: live` entries on the same identity: `live-dup-identity:` (identity is the approach noun — docs tree layout, TypeScript major, named-slot wrap — not a unique heading). Structural emitter flags two-or-more live docs-layout headings (`reorganiz` / `spec-docs` / `make-docs` / `docs/specs` / `docs suite`) with no supersede edge; other same-noun pairs are this pass's judgment.
   - `log.md` session headings are `## [YYYY-MM-DD] …`; drop `_No entries yet._` once a heading exists (`log-placeholder-stale:`). Non-session `##` headings outside fences (`bad-log-heading:` — not title or `## Format`). Session heading with no bullets underneath (`empty-log-heading:`). Same calendar day and same `[type]` update in place (`same-day-dup-log:`). `[type]` outside the closed list: `log-unknown-type:`. Canonical sources stay a short map (`index-catalog:` — max **3** bullets). Canonical bullet whose path `AGENTS.md` already links: `index-dup-agents:`. Memory link to missing `docs/` or ADR path: `memory-ghost-docs:`. Project-docs index on disk but omitted from `AGENTS.md`: `agents-docs-gap:`. Superseded decision that still has Context/Decision: `decision-body-bloat:`. Live + `**Source:**` to `docs/` or ADR + still Context/Decision: `decision-canonical-dup:`. Live Source-only and `AGENTS.md` already links that path: `decision-docs-map:`. Live Status whose heading or Source says superseded: `decision-stale-live:`. Incident-shaped decision (`src/` or `astro.config` plus rollback/workaround/Fragment/revert) with **no matching** learnings Relates/slug: `incident-unpromoted:` (per heading — one existing H2 does not skip the rest). Live decision with Context/Decision and a Relates to learnings (on the decision **or** a back-link in `learnings.md` / `learnings-*.md`): `decision-lesson-dup:`. Live decision names repo-relative paths and the index `decisions.md` line has no `when editing:`: `decision-hidden:`. Task starts with `Closed` or Next step is only delete/confirm-merged: `closed-placeholder-resume:`.
   - **Legacy mirrors** (`vision.md`, `architecture.md`, `patterns.md`, `domains/*`, `features/*`, plus `architecture/` / `components/` / `episodes/` / `changes/` / `timeline/` / `project.md`): `/agent-memory update` collapses them (`references/update-graph.md`). Leftover after skip → `graph-tree:` / `orphan:` here; unique-body leftovers → consolidate.
   **Done when:** every mismatch is a finding or checked clear.

4. **Dead paths.** Every relative Markdown link under `.agents/memory/` resolves (skip `./file` and `<…>` placeholders). Typed Relates targets exist, including `#fragment` (`relates-missing:`). Index links that point outside memory (`../../AGENTS.md`, `../../docs/…`) resolve. `when editing:` globs are repo-root, match at least one path (or are reported stale), and are not overbroad — see _Overbroad `when editing:`_. Path-scoped `learnings-*.md` index lines carry `when editing:` (`learning-hidden:`). Exact long-line copies of AGENTS/README/docs: `dup-exact:` (skip `instructions.md` ↔ `skills/agent-memory/vendor/memory/` dogfood).
   **Done when:** every miss is a finding.

5. **Typos.** Required headings match the template spelling (`typo-heading:` — `## In progres`, `## Next steps`, `## Validaton`, `## Checkpont`, `## Assumtions`). Method tokens use the canonical form (`typo-token:` — `when editting:`, `when-editing:`, `Checkpont:`, `Superceded`, bare `Relate:`, `Relates to:`). Do not spellcheck product English.
   **Done when:** every method-token misspelling is a finding or none remain.

6. **Instruction contradictions.** Memory vs method, vs other recall, vs canonical sources, vs the installed block.
   - `current.md` / `log.md` claim hooks or `.hook-sync-state` absent while state or a harness carrier exists: `blocker-hooks-contradiction:`.
   - Two Insights (or a decision pair) that conflict with no `contradicts` / `Contradicts:` edge: `contradicts-unlinked:`.
   - `Status: superseded` without `Superseded by:`, or A supersedes B and B supersedes A: `supersede-cycle:`.
   - Live decision vs code still implementing the rejected approach: note under Blockers (code/tests win on file facts; live decision wins on **approach**).
   - Memory vs ADR/README: Blockers, then fix or remove.
   - Installed `instructions.md` missing `## Write floor` or `## Recall hop`: `method-stale:` — suggest `/agent-memory update`.
   - An agent-memory block that lacks write floor / Reusable lesson / Skip is the default: `carrier-stale:` — suggest `/agent-memory update`.
   - Open `pending-doc` whose `Invalidate when` is still false is **healthy backlog** — do not report it. Only `pending-doc-met:` when the named doc already covers the Insight.
   **Done when:** every contradiction is a finding or checked clear.

7. **Agent quality (cold session).** With only always-on files open (`index.md`, `current.md`, `active-work/<branch>.md` if it exists), answer: (1) next concrete **product** step, (2) what must not break, (3) where to edit, (4) how to prove it worked. Each unanswerable question on open work is `quality-unanswerable:`. Open work (`active-work` or current In progress) plus **no** `when editing:` anywhere on `index.md` → `quality-unanswerable:` for “where to edit”. Next step is one product bullet (`stale-next-step:` when an action bullet cites `/agent-memory …`). Validation is an exact command and expected result. Progress does not replay `log.md` (`dup-progress-log` — structural: more than **5** Progress bullets). Hold max 3 bullets (`hold-overflow:`). Learnings are H2 with Insight / Evidence / Use when / Verified (`learning-missing-evidence`, missing Use when / Verified, **Legacy learning one-liner**). Evidence that names a recall file has `- Relates:` (`learning-missing-relates`). Unknown Relates verb: `unknown-relates-verb:`. Hypothesis sits under Assumptions, not as fact. One fact per bullet; links + delta — never pasted doc bodies. Soft budgets apply (below).
   **Done when:** all four cold-session questions are answered or listed; every quality finding is classified.

8. **Hook consistency.** Classify structural `hook-state-absent:` (info), `stale-resume:`, `evidence-stale-uncleared:`, `evidence-pending:`, `evidence-dirty-requeue:` (info unless Task / Progress / current-session `log.md` omit covering meaning — then escalate to `evidence-pending`). Five shared scripts travel together (`hook-incomplete:`). OpenCode loads `.opencode/plugins/` + `safe-script.ts` (`opencode-legacy-plugin:` on leftover `.opencode/plugin/`). Instruction wiring: `double-injection:`, `delegation-canary:`. Legacy hook Markdown leftovers: `legacy-touched-files:`, `legacy-path-bullet:`. Empty log after scaffold: `empty-log:` / `empty-log-after-scaffold:`.
   **Done when:** every hook finding has a band (errors / warnings / info).

9. **Report.** Group findings as **errors**, **warnings**, and **info**. Name the file and the problem. Omit empty bands. Do not promote info into warnings. Do not list open valid `pending-doc` anywhere in the report. If any **warning** maps to consolidate in the Fix map, end the report with: re-run `/agent-memory consolidate` until that band is empty.

10. **Fix offer.** Offer fixes **only** for errors and warnings — **never for info**. Look up each finding in _Fix map_. Confirm before editing user content.

## Overbroad `when editing:`

Reject **any** near-always-on glob in the hint list (companions do not redeem it). Normalize first: run **to fixpoint** — repeat until stable: strip a leading `./`, strip a leading `/`, and collapse `//` empty segments (so `/./hooks/**`, `/.//hooks/**`, `.//./hooks/**`, `././hooks/**`, `./hooks/**`, `.//hooks/**`, and `/hooks/**` all become `hooks/**`); reject any glob that still starts with `/` after normalize; then iteratively collapse `**/**` → `**`. Then reject (1) **structural** — two or more slash-separated segments that are each only `*`, `?*`, or `**` (e.g. `*/*`, `*/*/*`, `*/*/*/*`, `?*/*`, `?*/*/*`, `*/*/**`); also any glob with **no literal path segment** whose parts are only pure wildcards and/or `*.*` / `*.<ext>` at any depth (e.g. `*/*.*`, `*/*.<ext>`, `*/*/*.ts`, `*/*/*/*.json`, `?*/*/*.sh`, `*/*/*.*`); (2) **any** `**/*.<ext>` or `**/*.*`; (3) **any** `<top-level-dir>/**` and near-equivalents (`dir/**/*`, `dir/*/**`, `**/dir/**`) including `hooks/**`, `tests/**`, `docs/**`, `.agents/**`; (4) **explicit denylist** — including `**`, `**/*`, `**/**`, `**/**/*`, `*/**`, `*/*`, `?*/*`, `*/*/*`, `*/*/**`, `**/*/**`, `**/*/*`, `*`, `*.*`, `*.md`, `**/*.md`, `**/*.*`, `*/*.*`, `**/*.ts`, `**/*.tsx`, `**/*.js`, `**/*.jsx`, `**/*.py`, `**/**/*.ts`, `**/*/*.ts`, `*/**/*.ts`, `src/**`, `src/**/*`, `src/**/**`, `src/pages/**`, `pages/**`, `lib/**`, `app/**`, or `packages/**`. Prefer path-scoped globs with evidence: copy the Evidence path literals (max 3), or one immediate parent directory of those files — do not widen to a covering `**` tree.

## Soft budgets (warnings only)

Count non-empty lines:

- `current.md` > 30 → warn bloat.
- each `active-work/*.md` (except TEMPLATE) > 45 → warn bloat.
- `index.md` > 80 → warn bloat.
- `log.md` > 30 session headings (`^## \[`) → suggest consolidate.
- `decisions.md` > 200 → `/agent-memory consolidate` Pass A (Reference / drop `decision-docs-map`; collapse `decision-canonical-dup`) — not a learnings topic split.
- any `learnings.md` / `learnings-*.md` > 200 → suggest topic splits or consolidate merge (do not auto-split).
